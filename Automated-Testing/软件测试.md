
软件测试.

1. 单元测试（Unit Test）
      ├── 函数测试
      ├── 类测试
      ├── 方法测试
      ├── 异常处理测试
      ├── 边界值测试
      └── Mock 测试

2. 集成测试（Integration Test）
      ├── 接口集成测试
      ├── 模块集成测试
      ├── 数据库集成测试
      ├── 第三方服务集成测试
      ├── API 集成测试
      └── 微服务集成测试

3. 系统测试（System Test）
      ├── 功能测试（Functional）
      ├── E2E 测试（End-to-End）
      ├── 性能测试（Performance）
      │   ├── 负载测试（Load）
      │   ├── 压力测试（Stress）
      │   ├── 容量测试（Capacity）
      │   └── 稳定性测试（Soak）
      ├── 安全测试（Security）
      ├── 兼容性测试（Compatibility）
      ├── 可用性测试（Usability）
      ├── 安装/升级测试
      ├── 恢复测试（Recovery）
      └── 回归测试（Regression）

4. 验收测试（UAT）
      ├── Alpha Test
      ├── Beta Test
      ├── 用户验收测试（Business UAT）
      ├── 合同验收测试
      └── 运营验收测试（OAT）


| 名称     | 说明                                                                                         |
|----------|----------------------------------------------------------------------------------------------|
| 恢复测试 | 通过人为制造故障，验证系统是否能够自动或快速恢复，并确保数据完整、业务连续、恢复时间符合预期 |
| 回归测试 | 修改了代码之后，重新测试原来正常的功能，确保修改没有引入新的 Bug                             |
